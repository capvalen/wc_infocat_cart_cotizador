Cotizador de WhatsApp integrado con WooCommerce. Agrega un botón "Cotizar" a los productos, abre un panel lateral para armar la cotización y la envía por WhatsApp con fecha y hora.

== Description ==

WC Infocat Cart Cotizador permite a los visitantes armar una cotización de productos y enviarla directamente a un número de WhatsApp configurable.

Características:

* Botón "Cotizar" junto al botón de compra de los productos de WooCommerce.
* Panel lateral (offcanvas) con imagen, nombre, cantidad y precio de cada producto.
* Total sumado automáticamente.
* Envío por WhatsApp con el detalle completo y la fecha/hora.
* Número de WhatsApp configurable desde una página de ajustes (guardado en la base de datos).
* JavaScript puro, sin jQuery y CSS propio, sin Bootstrap.

== Installation ==

1. Comprima la carpeta del plugin en un archivo ZIP.
2. En el administrador de WordPress, vaya a *Plugins > Añadir nuevo > Subir plugin*.
3. Seleccione el ZIP y haga clic en *Instalar ahora*.
4. Active el plugin.
5. Vaya a *Ajustes > Cotizador Infocat* e ingrese el número de WhatsApp (con código de país).

== Frequently Asked Questions ==

= ¿Requiere WooCommerce? =

Sí. El plugin necesita WooCommerce instalado y activo.

= ¿En qué formato se ingresa el número de WhatsApp? =

Solo dígitos, con código de país y sin espacios ni símbolos. Ejemplo: 51999999999
